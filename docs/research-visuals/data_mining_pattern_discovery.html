Association Rule Mining

Key Metrics

  • Support: P(A ∩ B) - How often together?
  • Confidence: P(B|A) - If A, how likely B?
  • Lift: P(B|A)/P(B) - Better than random?
  • Conviction: Dependency measure

Algorithms

  • Apriori - Classic, level-wise
  • FP-Growth - Pattern tree, faster
  • Eclat - Vertical format
  • Sampling approaches for scale

Discussion Questions

  • How to set support threshold?
  • Confidence vs lift: which matters more?
  • Handling rare but valuable patterns?
  • Temporal association patterns?

Pattern Taxonomy: What Makes a Pattern "Structural"?

Not all patterns are equal. Research distinguishes three types - only one is reliably mineable:

Type 1: Structural Constraint Patterns ✓
Clear causal mechanism: WHO forces WHOM to do WHAT
Example: Negative gamma exposure forces dealers to sell rallies and buy dips (regulatory constraint)
Testable Causal Predictable
Type 2: Statistical Regularities ⚠
Correlations without established causal mechanisms
Example: "Markets tend to rally in December" - correlation without explanation
Risky May Overfit
Type 3: Narrative Patterns ✗
Post-hoc storytelling without empirical validation
Example: "The squeeze happened because of Reddit" - not testable
Untestable Circular

Causal Identification: WHO → WHOM → WHAT

For a pattern to be "structural," it must identify a causal chain - not just correlation:

# Causal Pattern Template WHO: "Dealers with negative gamma exposure" ← Constrained agent WHOM: "Market participants buying/selling" ← Affected counterparty WHAT: "Forced to sell rallies, buy dips" ← Required action # This tests MECHANISM understanding, not correlation recognition # Pattern is valid if WHO cannot avoid WHAT under constraint conditions

Avoiding Overfitting: Data Obfuscation Testing

How do you know if a discovered pattern is real vs memorized from training data? Obfuscation testing strips contextual cues to test structural reasoning:

Preserved (Structure)

  • ✅ Quantitative values (raw metrics)
  • ✅ Relationships (ratios, distances)
  • ✅ Distributions (concentrations)
  • ✅ Sequential ordering

Removed (Context)

  • ❌ Real dates → "Day T+0"
  • ❌ Real names → "ENTITY_A"
  • ❌ Calendar info (day of week)
  • ❌ Event references

Why This Matters

  • Tests if pattern is structural vs memorized
  • Prevents "training data leakage"
  • Forces reasoning from data alone
  • Validates generalization potential
# Obfuscation Example ORIGINAL: Date: 2021-01-27 | Ticker: GME | Event: Reddit squeeze OBFUSCATED: Day T+0 | STOCK_A | [context removed] # If pattern detection works WITHOUT context → Structural pattern ✓ # If detection requires context → Narrative pattern (overfit risk) ✗

What Makes a Pattern "Interesting"?

  • Actionable: Can we do something with this knowledge?
  • Unexpected: Does it tell us something we didn't know?
  • Valid: Does it hold up on new data (generalization)?
  • Novel: Is it previously undocumented?
  • Understandable: Can a domain expert interpret it?
